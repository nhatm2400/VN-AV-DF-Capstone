# Run của hướng lip-sync mới

Chưa có run huấn luyện mới. Mỗi run sau này có thư mục riêng chứa config, source_state, environment, dataset_snapshot, history, predictions, metrics và checkpoint local. Không ghi đè run đã hoàn tất.

Thí nghiệm AVSP-Net cũ đã chuyển vào docs/archives/legacy_avsp/experiments. Smoke test tổng hợp chỉ chứng minh plumbing; không được ghi thành kết quả accuracy.
